# Template Kampus

Letakkan file template LaTeX resmi dari kampus/departemen di folder ini (mis. `.cls`, `.sty`, contoh `.tex`, logo).

Setelah itu, minta agent: *"Sesuaikan thesis/main.tex dengan template di thesis/template-kampus/"*.
File bab (`bab1`–`bab5`) tetap dipakai; yang diganti hanya preamble dan halaman awal di `main.tex`.
