## 1. Arahan pembimbing (sebagaimana disampaikan)
1. **Fokus ke Citra:** Tinggalkan data tanpa citra (CyTOF). Riset difokuskan murni pada sistem visual/optik.
2. **K-Fold Cross-Validation:** Terapkan pembagian data baku: Training, Validation, Testing. Lakukan validasi model ML dengan K-Fold Cross-Validation (5-fold / 10-fold) pada data citra fluoresensi heiDATA.
3. **Pahami Makna Fisis & Rumus Matematis Fitur:** Ciri khas Teknik Fisika adalah memahami fisika dan matematika dari fitur yang diekstrak (contoh: apa arti fisis dan rumus matematis dari *circularity*, *solidity*, dsb.), bukan sekadar memakai ML secara *black-box*.
4. **Pergantian Judul:** Tanyakan mekanisme pergantian judul ke bagian Pengajaran/Akademik Fakultas.
5. **Jadwal Senin:** Hasil validasi k-fold dilihat hari Senin, 9 November 2026 bersama pembimbing.

## 2. Definisi selesai
- [ ] Pipeline training ML citra heiDATA mengimplementasikan K-Fold Cross-Validation (5-fold / 10-fold).

- [ ] Diperoleh angka metrik evaluasi hasil K-Fold CV (akurasi rata-rata, standar deviasi, ROC-AUC, F1-score).
- [ ] Informasi dari bagian akademik terkait prosedur pergantian judul SIMASTER terdokumentasi.

---

## 3. Rencana langkah kerja
1. **Penyusunan Formularium Fitur Fisis/Bio-Optik:**
   - Ekstrak rumus matematis untuk: Luas ($Area$), Keliling ($Perimeter$), *Circularity* ($4\pi \cdot Area / Perimeter^2$), *Solidity* ($Area / ConvexArea$), *Eccentricity*, *Aspect Ratio*, *Intensity Mean/Max/Std*, dan rasio konsentrasi tepi/inti Lamin B1.
   - Tuliskan tafsiran fisisnya dalam konteks deformasi membran inti akibat infeksi HIV.
2. **Implementasi K-Fold Cross-Validation di Script ML / Google Colab:**
   - Buat skrip pembagian data dengan `StratifiedKFold` (mis. 5-fold dan 10-fold).
   - Pastikan evaluasi memisahkan Training, Validation, dan Testing set secara ketat untuk mencegah *data leakage*.
   - Catat metrik per-fold dan rata-rata performa.
3. **Konsultasi ke Pengajaran:**
   - Tanyakan mekanisme pergantian judul (apakah butuh formulir khusus atau cukup penyesuaian saat pendaftaran pendadaran).
4. **Persiapan Bahan Bimbingan 6 (Senin, 9 Nov 2026):**
   - Ringkas hasil evaluasi K-Fold CV dan sajikan dalam bentuk grafik / tabel untuk ditunjukkan ke Pak Nopriadi.
