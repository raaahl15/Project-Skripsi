## 1. Arahan pembimbing (sebagaimana disampaikan)
"Tugasmu bukan sekedar membuat program deeplearning untuk menghasilkan akurasi terbaik, tapi mengetahui karakteristik fisik/bio-optik apa yang membedakan sel normal, terinfeksi, dan mati. Karena ini penelitian, lakukan ekstraksi fitur dan Deep Learning tidak bisa melakukan itu."

## 2. Definisi selesai
- Fitur fisik/bio-optik per sel terdefinisi dan terekstraksi dari citra
- Fitur pembeda tiap kondisi teridentifikasi (uji statistik / feature importance) dan ditafsirkan secara fisis

## 3. Rencana langkah kerja
1. Segmentasi sel/inti
2. Ekstraksi fitur morfometri, intensitas, tekstur, lokasi sinyal
3. Analisis fitur pembeda
4. Tafsirkan secara fisis/biologis
